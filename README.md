# 经纬 · 欧美智库目录

可搜索、筛选、比较的欧美代表性智库目录，覆盖美国、英国与欧洲大陆的 33 家机构。

## 在线访问

公开站点：<https://think-tank-atlas.reagan-park-6434.chatgpt.site>

本仓库已包含 GitHub Pages 工作流；在仓库 Settings → Pages 将部署源设为 **GitHub Actions** 后，每次推送到 `main` 均会发布 `dist/` 的静态站点。

## 功能

- 按地区、国家、机构类型、研究领域和关键词筛选
- 机构档案：官网、研究领域、资金来源、立场／研究风格与 RSS 入口
- 最多四家横向比较；比较表可编辑、移除或清空机构
- 在档案内编辑研究领域和立场标签；自定义内容会保存到当前浏览器，并影响筛选、比较和 CSV 导出
- 对 10 家重点机构补充资金来源或资金结构与官方披露出处

## 快速运行

```bash
npm run dev
```

默认打开 <http://localhost:3000>。

## 数据使用说明

本项目是代表性研究目录，并非排名。立场／研究风格为便于比较的编辑性归类，不等同于机构的自我定义、党派隶属或对研究质量的评价；每条档案均提供机构公开定位依据。RSS 入口为按机构官网域名限定的 Google News RSS 聚合链接，以保证所有机构均有统一订阅入口；不应理解为所有机构均提供官方原生 RSS feed。

机构官网与公开披露可能变化。欢迎通过 Issue 或 Pull Request 提交勘误、补充和更新。

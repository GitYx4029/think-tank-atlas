# 架构说明

项目为无构建步骤的静态单页应用：

```
dist/
  index.html    页面结构和弹窗
  style.css     响应式样式
  app.js        筛选、比较、编辑与 CSV 导出
  data.js       机构目录及来源链接
server.mjs      本地静态文件服务器
```

## 运行逻辑

1. `data.js` 导出基础机构记录。
2. `app.js` 读取记录并渲染筛选器、卡片、档案和比较表。
3. 用户对研究领域、立场和说明的修改保存在浏览器 `localStorage` 的 `think-tank-edits-v2` 键中。
4. 自定义字段会实时参与关键词搜索、领域筛选、横向比较与 CSV 导出；不会写回远端数据文件。

## 设计边界

- 无账号、后端数据库或第三方 API。
- 所有基础数据均可在 `dist/data.js` 审阅。
- 生产环境只需托管 `dist/` 目录。

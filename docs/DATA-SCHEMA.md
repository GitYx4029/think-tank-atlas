# 数据字段与维护规范

每条机构记录包含：

| 字段 | 含义 |
| --- | --- |
| `short/name/full` | 缩写、中文名、英文或原文名 |
| `country/city/region` | 所在国家、城市和地区分类 |
| `type` | 机构类型（第一层单选） |
| `topics` | 研究领域数组（第二层多选） |
| `roles` | 功能角色数组（第三层多选） |
| `summary` | 简短研究简介 |
| `website/source` | 官方网站及机构介绍／研究领域依据 |
| `funding/fundingSource` | 资金结构摘要及官方披露链接（重点机构） |
| `stance/stanceNote/stanceSource` | 编辑性立场标签、归类说明及公开定位依据 |
| `rss` | 按官网域名限定的 RSS 聚合订阅地址 |
| `verified` | 最近核验日期 |

## 更新原则

1. 官网、所在地、领域和资金信息优先引用机构自身的关于、财务、年报或捐助披露页面。
2. `type` 只能在以下 MECE 类型中单选：政府／公共部门内设型、准政府／公共授权型、大学／学术机构附属型、政党／政治基金会附属型、企业／行业／商业支持型、独立非营利／民间社会型、多主体联盟／网络型、未核验／信息不足。类型按治理与正式隶属关系判定，不能由单一捐助者或资助项目推断。
3. `topics` 使用统一研究领域词表，必要时允许在档案内新增；`roles` 为可多选的编辑性功能标签。
4. “立场／研究风格”应采用审慎、可解释的描述；对不适合左右光谱的学术或公共研究机构，优先使用“中立／技术官僚型”“公共政策顾问型”等标签。
5. 不把“非党派”直接等同于“没有价值取向”；同时也不将编辑性归类表述为机构自我认定。
6. 机构原生 RSS 缺失或不稳定时，保留统一的官网域名 RSS 聚合入口。
